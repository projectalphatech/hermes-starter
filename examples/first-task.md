# First task: copy this to Hermes

Run `hermes` inside an empty folder, then paste:

```text
اعملي صفحة ويب واحدة (index.html) لمطعم كشري اسمه "كشري التحرير":
عنوان كبير، منيو فيها 5 أصناف بالأسعار بالجنيه، زرار "اطلب على واتساب"، وألوان حلوة.
اكتب الملف في الفولدر ده، وقولي أفتحه إزاي.
```

English version:

```text
Build a single web page (index.html) for a koshary restaurant called "Koshary El Tahrir":
a big title, a menu with 5 items and prices in EGP, an "Order on WhatsApp" button, and nice colors.
Write the file in this folder and tell me how to open it.
```
